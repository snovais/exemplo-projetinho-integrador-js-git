# 🚀 Projeto Coletivo: Vitrine de Serviços e Agendamento

Este é um projeto prático de página única (Single Page) desenvolvido em equipe. O objetivo principal é aplicar conceitos básicos de HTML5, CSS3 e JavaScript, além de praticar o fluxo de trabalho e versionamento de código utilizando o Git e GitHub.

*   **[Nome do Aluno 2]** - Desenvolvedor (Cores e Interatividade dos Botões com JS)
*   **[Nome do Aluno 3]** - Desenvolvedor (Formulário Obrigatório e Validação com JS)

---

## 🛠️ Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica da página.
*   **CSS3:** Estilização, layout flexível (Flexbox/Grid) e elementos fixos (Header e Footer).
*   **JavaScript (Básico):** Manipulação de eventos de clique, alteração de classes CSS e validação de campos de texto.
*   **Git & GitHub:** Controle de versão e integração do trabalho em equipe através de branches.

---

## 📑 Funcionalidades do Projeto

1. **Estrutura Fixa (Aluno 1):** O site possui um cabeçalho (Header) e um rodapé (Footer) que permanecem fixos na tela enquanto o usuário navega pelo conteúdo.
2. **Seleção de Cards (Aluno 2):** Ao clicar no botão de um dos cards de serviços, o fundo do card e a cor do botão mudam de cor para indicar a seleção, alterando também o texto para "Selecionado ✔️". É possível selecionar apenas um card por vez.
3. **Formulário Obrigatório (Aluno 3):** Um formulário de agendamento que captura o "Nome" e o "E-mail" do usuário. O sistema valida se os campos estão vazios e se o usuário escolheu um serviço antes de simular o envio.
